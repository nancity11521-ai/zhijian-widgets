2 产品定位、核心理念与目标场景
维度 需求定义与业务目标
产品定位 融合 5×7 LED 点阵硬件美学与现代暗黑极简工业风的桌面小组件系统，适配桌面端/移动端 Web、PWA 及嵌入式桌面启动器。
核心理念 “至简·硬核·直觉”：摒弃花哨装饰，以高对比度单色/撞色卡片、发光点阵数字、精准网格几何与直觉交互，呈现纯粹高效的信息聚合体验。
目标用户画像 1. 追求个性化科技复古美学的极客与设计师；
2. 偏好一目了然获取时间、日程、天气、传感器数据的高效数字游民；
3. 户外探险、手持硬件、三防终端或工业控制台桌面 UI 需求用户。
四大核心场景 1. 日常效率：时钟、公历/农历、待办事项、电量与重要纪念日；
2. 健康生活：步数实时统计、每日喝水打卡、音乐播放沉浸反馈；
3. 户外环境：海拔高度、气压监测、指南针定向、手电筒、噪音分贝测量与雨盾模式；
4. 极客与硬件：无网通信自组网（Mesh）、FM收音机、后台隐蔽录像、环境氛围灯与投影仪中控。

4 5×7 LED 点阵与矢量几何渲染技术引擎
引擎模组 技术实现原理 规范要求与输入输出
点阵字库 (F-Engine) 5×7 二值化像素字典 (0/1 字符串) 完整覆盖数字 0-9、符号 (: . / - %)、大写字母 A-Z，支持任意文本自定义映射。
点阵生成器 (drawDM) 动态 SVG / DOM 像素矩阵绘制 解析 data-dm 属性，自适应拼接 5×7 单元。支持 data-color 自定义颜色与 data-glow 发光辉光。
硬件底槽模组 物理常亮暗像素网格 (Dark Dots) 每个字符保留未激活的 0 位点阵（透明度 9%），高度模拟物理发光二极管底板。
模拟表盘引擎 纯前端几何坐标变换时钟 点阵外圈刻度 + 矩形时针 + 细长分针 + 橙色独立跳秒点，支持系统时钟同步驱动。

W3 模拟时钟 (橙底) 4×2 时间信息 点阵机械表盘 + 农历日期 + 治愈诗句 + 7 天胶囊周条（高亮当天） 秒级走动，周条自动选中今日日期胶囊
W4 待办事项 (Todo) 2×2 健康生活 月日标头 + 3 条精选待办事项 + 方形复选框 点击单条任务切换完成状态（打勾高亮、文字划线淡化）
W5 综合天气大卡 4×2 天气环境 巨幅气温点阵 + 气象符号 + 今日/明日双预报卡 + 今日剩余时间 点击卡片轮换城市（多伦多、北京、上海、深圳）
W6 喝水打卡 (蓝底) 2×2 健康生活 已饮杯数大点阵数字 + 水杯容量矢量图 + 独立加减按钮 点击“+”增加水量（上限8杯），点击“-”减少，水杯透明度同步随量变化
W7 倒计时 I (生日) 2×2 效率生活 生日剩余天数点阵 + 出生日期设置 (2000/02/20) + 蓝色滑块条 按系统当前日期动态计算展示，过生日自动切下一年
W8 月历单日 (橙底) 2×2 时间信息 超大 5×7 点阵当前日期 + 农历月日 + 星期全称胶囊 每日零点自动翻页，纯粹大字展示
W9 网易云音乐胶囊 2×2 娱乐生活 黑胶唱片拟物图形 + 听歌识曲标签 + 播放/暂停控制按钮 点击播放按键：黑胶唱片平滑旋转动效启动/暂停
W10 极简模拟时钟 (橙底) 2×2 时间信息 156px 纯模拟点阵指针时钟表盘，极简工业风 秒级连续走动，桌面美学挂件
W11 日期+多维剩余进度环 2×2 时间信息 月日点阵 + 农历文本 + 3 个微型圆环（年剩余%、月剩余%、日剩余%） 每秒刷新圆环 Stroke 与内嵌微型点阵百分比
W12 倒计时 II (纪念日) 2×2 效率生活 纪念日倒数剩余天数大点阵 + 目标纪念月日胶囊 (MAR 21) 动态根据系统日期计算剩余天数
W13 迷你时钟 2×2 时间信息 点阵时钟 + 完整公历年月日行 + 星期/天气简报条 时间随秒走动，天气跟随全局城市联动更新
W14 迷你天气 2×2 天气环境 点阵温度 + 拟真天气图标 + 气温极值范围 与主天气卡状态同步联动，垂直紧凑布局
W15 电子指南针 (Compass) 2×2 户外工具 外圆方位刻度盘 (N/E/S/W) + 经典红白双色磁针 点击卡片触发随机转动阻尼动画，模拟真实寻北定位
W16 一周天气预报趋势 4×2 天气环境 左侧大温度点阵与城市英文名 + 右侧 6 天逐日预报柱状图 点击卡片切换城市并刷新未来 6 天逐日数据
W17 手电筒快捷控制 2×2 实用工具 拟物手电筒身 + 扇形发光光束 + ON/OFF 状态提示 点击卡片切换手电筒开关（光束显隐与状态文字变更）
W18 海拔高度与气压计 2×2 户外传感 海拔点阵数值 (m) + 气压点阵数值 (hPa) + 中轴硬件分隔虚线 点击卡片触发传感器微幅扰动重采样模拟 (海拔±3m, 气压±2hPa)
W19 便携录音机 (Recorder) 2×2 系统工具 麦克风/声波状态点阵 + 录制计时点阵 (mm:ss) + 红色闪烁录制灯 三态状态机：未录制(idle) -> 录制中(rec) -> 暂停(pause) 循环切换
W20 调频 FM 收音机 2×2 系统工具 收音机图标 + 频率大点阵 (MHz) + 调谐标尺指针 + 电台名 右上角开关机 (ON/OFF)；开机状态点击卡片循环切换 3 个广播频点
W21 计步器 (Pedometer) 2×2 健康生活 步数点阵 + 达成率百分比胶囊 + 分段进度条 + 里程(km)/热量(kcal) 点击卡片随机累加 300~700 步，动态刷新进度条，达到1.2万步循环
W22 无网通信 (Mesh) 2×2 应急通信 信号发射塔图标 + 通信半径 (km) 点阵 + 已连接设备数 点击卡片循环切换组网拓扑半径与在线节点数
W23 噪声测试计 (dB) 2×2 环境测量 分贝点阵数值 + 6 段双色电平柱 + 状态胶囊（安静/正常/嘈杂） 点击卡片重新采样分贝，重算电平点亮高度与安全阈值说明
W24 后台隐蔽录像 2×2 安全工具 摄像机点阵图标 + 录像时长点阵 (mm:ss) + 摄录红点呼吸灯 支持未录制、录制中、暂停录像三态切换
W25 雨盾模式 (防误触) 2×2 三防防护 雨伞硬件点阵图标 + ON/OFF 点阵大字 + 湿手触控说明 点击卡片或药丸开关切换 ON/OFF，适配水下与雨天手套触控
W26 智能氛围灯控制器 2×2 智能家居 灯泡点阵 + 5 色点阵排灯 + 模式胶囊（呼吸/流光/常亮/渐隐） 点击卡片循环切换 4 种预设灯光模式与亮度色彩配比
W27 智能投影仪中控 2×2 硬件外设 投影机点阵 + ON/OFF 状态点阵 + 输入信源 (HDMI 1/2/DP/WIFI) 点击卡片开关电源，并轮询切换输入信号源通道

8 非功能性需求（NFR）与质量验收指标
质量维度 指标项 详细技术规范与测试验收标准
性能体验 首次内容绘制 (FCP) 全屏小组件与点阵渲染首屏 FCP 时间 <= 500ms，原生 JS 零第三方重量级框架依赖。
帧率稳定性 动画与定时器运行时帧率 时钟走针、唱片匀速旋转、指南针阻尼动画保持 >= 60 FPS，无丢帧及内存泄漏。
设备环境兼容 现代浏览器与多端适配 兼容 Chrome 90+、Safari 14+、Edge 及移动端 WebView；提供横向滚动与视口自适应支持。
视网膜高分屏 Retina 高清点阵清晰度 点阵使用矢量 SVG 与亚像素对齐算法，在高分屏（2x/3x）下点阵发光圆点锐利清晰。
容错与降级 农历算法安全降级 若环境不支持 Intl.DateTimeFormat chinese 历法，平滑静默回退至标准公历，保证页面不白屏崩溃。
